# Luiza Klafke Janisch — E-Portfolio

Static e-portfolio prepared for GitHub Pages.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `eportfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will provide a public URL after deployment.

## Personalize before submitting
- Replace the portrait placeholder in `index.html` with your photo.
- Verify dates and wording of each professional experience.
- Add links/images/reports to project cards if available.
- Optionally add a downloadable English CV as `assets/Luiza_Klafke_CV_EN.pdf`.

## Add a photo
Create an `assets` folder and put `profile.jpg` inside it. Replace:
`<div class="portrait-placeholder">...</div>`
with:
`<img class="portrait-placeholder" src="assets/profile.jpg" alt="Luiza Klafke Janisch">`
